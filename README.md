# @voyation/dsh-novel-studio

## 安装

```bash
npx @deepseek-ai/dsh plugin --profile web add @voyation/dsh-novel-studio
```

使用同一 profile 启动 DSH：

```bash
npx @deepseek-ai/dsh --profile web
```

 DSH 的右侧侧边栏变成一个真正的小说阅读器，同时为 AI 提供操作小说的工具。

你在原本的对话区与 AI 交流，提出写作和修改要求；AI 通过工具读取、修改小说的正文、提纲、人物和设定、知识，结果直接呈现在右侧阅读器中。你可以像读小说一样阅读正在创作的内容，看着人物、情节和章节一步一步成形，看着整部小说逐步构建起来。

插件不规定创作流程。先写正文、先整理提纲，或随时调整人物与设定，都由你和 AI 决定。
